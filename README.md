# When Does Model Complexity Pay?
## A Controlled Comparison of Return and Volatility Forecasting

This repository contains the data, implementation scripts, and empirical results associated with the study:

**“When Does Model Complexity Pay? A Controlled Comparison of Return and Volatility Forecasting”**

The study investigates whether the forecasting value of model complexity depends on the financial prediction target. Using the SPDR S&P 500 ETF Trust (SPY) as a common underlying asset, the analysis compares one-day-ahead return forecasting with five-minute realized-variance (RV5) forecasting under a controlled experimental design.

Ridge regression provides a common regularized linear reference, while XGBoost and long short-term memory (LSTM) networks represent nonlinear tree-based and sequence-based forms of additional model flexibility. The historical mean and HAR-RV are retained as target-specific benchmarks.

All model selection is conducted using the development sample, with the final test period kept sealed until model configurations and evaluation procedures are fixed.

## Repository Contents

The reproducibility materials are distributed in three archives:

### `scripts.zip`

Contains the Python scripts used to construct the forecasting dataset, perform model selection, generate out-of-sample forecasts, evaluate forecast accuracy, conduct statistical tests, and produce the robustness analyses reported in the paper.

The computational workflow includes:

- data preparation and target construction;
- chronological train-validation-test construction;
- Ridge, XGBoost, and LSTM model estimation;
- historical-mean and HAR-RV benchmark estimation;
- validation-based hyperparameter selection;
- expanding-window out-of-sample forecasting with monthly re-estimation;
- RMSE, MAE, and out-of-sample R² evaluation;
- complexity-gain calculations;
- Diebold-Mariano forecast-accuracy tests;
- MAE sensitivity analysis;
- fixed-subperiod robustness analysis; and
- LSTM initialization-seed diagnostics.

### `datasets.zip`

Contains the datasets required to reproduce the empirical analysis.

The study uses SPY market information and constructs two one-day-ahead forecasting targets:

1. daily log return; and
2. five-minute realized variance (RV5).

The common predictor set consists of nine variables:

`ret1`, `ret5`, `ret22`, `rv1`, `rv5avg`, `rv22avg`, `lvol`, `dlvol`, and `range`.

The final matched supervised dataset contains **2,532 observations**, divided chronologically into:

- **Training:** 1,494 observations (2003–2014)
- **Validation:** 424 observations (2015–2017)
- **Final test:** 614 observations (2018–2021)

Split membership is determined by the target date.

RV5 is constructed using valid adjacent observations on a fixed five-minute intraday grid. Missing endpoints are not interpolated, substituted, carried forward, or bridged.

### `results.zip`

Contains the outputs generated by the empirical pipeline, including model-selection results, final out-of-sample forecasts, performance metrics, statistical-test outputs, robustness results, figures, and supporting audit artifacts.

These files provide the numerical basis for the tables, figures, and empirical findings reported in the manuscript.

## Experimental Design

The experiment is designed to compare model flexibility across forecasting targets while holding several major dimensions of the forecasting environment constant.

| Component | Specification |
|---|---|
| Underlying asset | SPDR S&P 500 ETF Trust (SPY) |
| Forecast horizon | One trading day ahead |
| Targets | Daily log return and RV5 |
| Learned models | Ridge, XGBoost, LSTM |
| Return benchmark | Historical mean |
| RV5 benchmark | HAR-RV |
| Model-selection criterion | Validation RMSE |
| Test observations | 614 |
| Final estimation | Expanding information set |
| Re-estimation frequency | Monthly |
| Primary accuracy measure | RMSE |
| Complementary measure | MAE |
| Statistical comparison | Diebold-Mariano test |

The primary measure of incremental model complexity is the percentage reduction in RMSE relative to Ridge:

$$
CG_{m,y} = 100 \times
\frac{RMSE_{\mathrm{Ridge},y} - RMSE_{m,y}}
{RMSE_{\mathrm{Ridge},y}}
$$
Positive values indicate that the more flexible model improves upon Ridge, whereas negative values indicate deterioration.
